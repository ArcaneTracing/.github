# GitHub metadata

This folder holds organization and repository metadata used on GitHub.

- **[`profile/README.md`](./profile/README.md)** — Optional **organization profile** README (shown on `https://github.com/ArcaneTracing` when configured in org settings).

CI workflows, issue templates, and other automation normally live under `.github/workflows/` and related paths at the **repository root** (sibling of this `backend/`, `frontend/`, etc.). See the root [`CONTRIBUTING.md`](../CONTRIBUTING.md) for how to contribute.
